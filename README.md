# ЗНАК* — цифровой оракул

Демо-сайт на чистых HTML, CSS и JavaScript. Сервер и установка зависимостей не нужны.

## Запуск

1. Распакуйте архив целиком.
2. Откройте `index.html` в современном браузере.
3. Для корректной загрузки иллюстраций не перемещайте папку `assets` отдельно от `index.html`.

## Что внутри

- 8 направлений: предсказание дня, карта дня, любовь, деньги и работа, судьба, безумие, совет вселенной, хрустальный шар.
- 1 040 вариантов контента: 130 предсказаний в каждом из 6 тематических режимов, 220 ответов хрустального шара и 40 авторских карт.
- Колода из 40 отдельных изображений, галерея карт и ежедневная карта.
- Персональное обращение, история, избранное, копирование и системная отправка результата.
- Защита от повторов до полного перебора пула каждого режима.
- Секретные знаки, анимации, адаптивная вёрстка и режим уменьшения движения.

Данные имени, истории, избранного и использованных знаков сохраняются локально в браузере через `localStorage`.

## Публикация на GitHub Pages

1. Создайте на GitHub новый репозиторий, например `znak-oracle`.
2. Распакуйте архив и откройте папку `znak_oracle_site`.
3. Загрузите **всё содержимое этой папки** в корень репозитория: `index.html`, `README.md` и папку `assets`. Не загружайте только ZIP и не оставляйте `index.html` внутри дополнительной вложенной папки.
4. Откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**.
6. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
7. После публикации адрес сайта будет иметь вид `https://ВАШ-ЛОГИН.github.io/znak-oracle/`.

Для загрузки через сайт GitHub можно использовать **Add file → Upload files**. Веб-интерфейс принимает до 100 файлов за одну загрузку; в проекте меньше этого лимита. Все изображения из `assets` нужно сохранить вместе с сайтом.
